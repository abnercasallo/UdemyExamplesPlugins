# Theme Reference — Office Standards

Four predefined visual themes for PowerPoint, Word, and Excel. All themes share the same palette across document types to ensure cross-document consistency.

---

## Theme 1: Corporativo Azul

**Personality**: Formal, trustworthy, executive.
**Best for**: Financial reports, board presentations, executive summaries, legal documents.

| Role            | Color Name     | Hex       | Use                                      |
|-----------------|----------------|-----------|------------------------------------------|
| Primary         | Navy Blue      | `#1B3A6B` | Headings, slide backgrounds, header rows |
| Secondary       | Gold           | `#C9A84C` | Accents, dividers, chart highlights      |
| Background      | White          | `#FFFFFF` | Slide/page background                    |
| Text primary    | Dark Navy      | `#0D1F3C` | Body text                                |
| Text secondary  | Medium Gray    | `#6B7280` | Subtitles, captions, footnotes           |
| Surface         | Ice Blue       | `#EEF2F9` | Alternating table rows, sidebars         |

**Typography:**
- Heading font: Garamond Bold (or Georgia Bold as fallback)
- Body font: Calibri Regular
- Heading size (pptx): Title 40pt, Subtitle 24pt, Body 18pt
- Heading size (docx): H1 24pt, H2 18pt, H3 14pt, Body 11pt
- Heading size (xlsx): Column headers 11pt Bold, Data 10pt Regular

**PPTX specifics:**
- Slide background: `#FFFFFF`
- Title bar fill: `#1B3A6B`, text `#FFFFFF`
- Accent shape fill: `#C9A84C`
- Chart palette: `#1B3A6B`, `#C9A84C`, `#4A7BC8`, `#A0522D`, `#6B9BD2`

**DOCX specifics:**
- H1 color: `#1B3A6B`
- H2 color: `#2B5EA7`
- Accent border / horizontal rule color: `#C9A84C`
- Table header fill: `#1B3A6B`, text `#FFFFFF`
- Table alternating row fill: `#EEF2F9`

**XLSX specifics:**
- Header row fill: `#1B3A6B`, text `#FFFFFF`, bold
- Alternating data rows: `#EEF2F9` / `#FFFFFF`
- Total/summary row fill: `#C9A84C`, text `#0D1F3C`, bold
- Chart default colors: `#1B3A6B`, `#C9A84C`, `#4A7BC8`

## Cross-document consistency rules

When applying themes across multiple document types for the same project:
1. Always use the same theme number across all files in the set.
2. The primary color should appear as the dominant header/title color in all three document types.
3. The secondary (accent) color should be used for callouts, totals, and highlights consistently.
4. Font families should match as closely as possible — use the same fallback fonts if the primary font is not installed.
5. Table header styles must be identical in color across docx and xlsx files.
